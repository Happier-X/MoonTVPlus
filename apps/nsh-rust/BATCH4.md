# 批 4：真实详情与选集交接

## 本轮改动

- `src/detail.rs`：详情状态、真实片源查找、选源/选集 tabs、加载与失败重试、播放选择状态。
- `src/lib.rs`：搜索海报与首页卡片进入详情；四分类最小列表入口；用真实选集 URL 替换播放页固定探测源。
- `src/search.rs`：复用既有 SearchItem 解析器，不另造接口字段。

接口依据：仓库 `src/app/api/search/route.ts` 的 `results`、`src/app/api/detail/route.ts` 的 `source/id`，以及 `src/lib/types.ts` 的 `SearchResult`（`episodes` / `episodes_titles` / `desc` 等）。鉴权请求复用已有 api() 的 refresh 一次逻辑；刷新后的 token 持久化并同步代理。旧标题/旧选源的异步详情响应不覆盖新的选择。

搜索卡片保留 source/id，并把当前聚合结果里同名同年份的所有源交给详情；首页/分类卡片不把豆瓣或番剧 ID 冒充片源 ID，而通过站点 `/api/search?q=` 查找同名真实片源。无匹配时明确失败，不替换成演示源。换源页允许重新查找，以补充搜索首次打开详情时尚未到达的源。

选集保留影片、source/id、集数索引与真实 URL，交给现有 `/a.m3u8?u=` + 内置 Video 播放入口。播放页返回详情，详情返回其入口页。未添加完整控制条、续播上报、清晰度、字幕、弹幕。

## 用户运行清单（均待执行）

1. 搜索一部有多源影片，点击网格卡：确认只有真实 source/id 用于详情请求，能显示标题、海报、年份和简介。
2. 打开换源 tab，点击不同源：确认当前源标记变化、集数更新；慢源返回不应覆盖后选源。
3. 使用失败源/断网：确认错误提示、重试当前源与重新查找片源可用；无源不进入演示播放。
4. 点击不同集数：确认播放页显示正确影片、源名和集数，URL 来自该集；HLS 是否出画由运行结果判断。
5. 播放页返回详情，再返回搜索/分类：确认原搜索快照/分类列表仍在。
6. 首页与电影/剧集/动漫/综艺卡片：确认先查真实片源再加载集数，而非使用目录 ID 直接请求详情。
7. 模拟鉴权 401：确认 refresh 一次，成功后后续详情及代理使用新 token；refresh 失败才登出。公开分类接口 401 不清会话。
8. 浅深主题检查布局、空源和错误状态；本轮没有新截图。

## 待确认与限制

- 未做 Android 编译/运行，真实接口、播放、返回手势及视觉效果都待用户实测。
- 同名搜索严格匹配片名和可用年份，别名/繁简差异可能无匹配；可返回搜索另一个名称，不静默选无关影片。
- 详情说明可能含网页 HTML，目前作为普通文本展示，不解释执行 HTML。
- 播放仍复用既有 HLS 本地代理，不新增网页解析或非 HLS 直放能力；已有代理使用 directplay 规则，而非新增站点 source 专用策略。
- 换源只重新选择内容，不保证跨源进度保持；续播与进度上报属于批 5。
