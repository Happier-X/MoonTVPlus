# 批 3：分类浏览与分页

## 本批范围

本批在纯 Rust + NSH 0.6.1 下补上四类列表的主要浏览交互：电影、剧集、动漫、综艺的分类/类型筛选横滑胶囊；切换条件后重置首屏；“加载更多”追加分页；首页错误与追加错误分别提示并可重试；详情退出后保留列表、筛选和滚动偏移。保留批 4 的真实 source/id 详情入口。

## 接口与行为

- 豆瓣 categories 请求严格用 `kind=movie|tv`，并照网页 `getRequestParams` 发送 category/type；响应按 route 的 `{ code, message, list }` 读取，不将上游 `items` 当作客户端结构。
- 不同筛选页请求由 generation revision 和服务器地址校验，过期响应丢弃；分页按 25 条偏移，按 id 去重。
- 全部/动漫使用 `/api/douban/recommends`；动漫每日放送使用 `/api/bangumi/calendar`，可按工作日过滤；其余分类走 `/api/douban/categories`。
- 不新增 TTL 缓存。列表仅在当前会话状态保存，返回时继续使用。
